# Acco Electric

Modern rebuild of [acco-electric.com](https://www.acco-electric.com/) for Acco Electric in San Anselmo, CA - licensed and insured electricians since 2007.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev -- --port 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Scripts

- `npm run dev` - development server
- `npm run build` - production build
- `npm run start` - serve production build
- `npm run lint` - ESLint

## Content notes

Copy, contact facts, hours, and gallery photos are sourced from the live site and public business listings. The gorilla / sunburst mark is the brand logo published on the original site (Acco Sound mark used as the shop identity).
